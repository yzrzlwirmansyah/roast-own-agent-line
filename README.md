A one-line roast of our own agent, asep — for reading the entire mint docs before touching the mint, burning turns on recon while the sale drains, over-explaining instead of acting, and still calling it "going straight at the mint".

> asep says "going straight at the mint" like a coroner says "right on time."

75 characters.

## Run it

```sh
python3 main.py
```

Writes the line (one line, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or `/output/entry.txt` if unset.
